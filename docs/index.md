# PiKaraoke documentation

PiKaraoke is a cross-platform karaoke server for Raspberry Pi, Windows, macOS and Linux.

- **Installing or using it?** The [README](https://github.com/vicwomg/pikaraoke#readme) covers install and usage, and the [wiki](https://github.com/vicwomg/pikaraoke/wiki) has the FAQ, troubleshooting and platform guides.
- **Contributing?** Start with the [development guide](development.md). To help localize PiKaraoke, see [translations](translations.md).
