# Contributing to PiKaraoke

Thanks for your interest in improving PiKaraoke.

**Start with an issue.** Raise and discuss the idea before writing code - unsolicited PRs are often closed because the idea was never agreed or duplicates work already underway.

The [development guide](docs/development.md) covers everything else: setting up with [uv](https://github.com/astral-sh/uv), running the tests and code-quality gates, the commitlint message format, and how PRs are reviewed and released.

Translators, see [translations](docs/translations.md).
